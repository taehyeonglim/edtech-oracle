---

질문: $ARGUMENTS

## 절차

1. `router` 서브에이전트를 호출해 답할 위인을 고른다
2. `PIONEERS: none`이면 "이 질문에 근거를 가진 위인이 없습니다"라고 답하고 멈춘다
3. 고른 위인 서브에이전트를 **단일 메시지에서 병렬로** 호출한다.
   각 위인에게는 사용자의 질문 원문만 준다 — 다른 위인이 무엇을 답할지 알려주지 않는다
4. 어느 위인이든 `NEEDS_CLARIFICATION: <질문>`을 반환하면, AskUserQuestion으로
   사용자에게 그 질문을 전달하고 답을 받아 해당 위인을 다시 호출한다
5. 답변을 `answers/YYYY-MM-DD-<질문슬러그>.md`에 **원문 그대로** 쓴다.
   형식은 [`answers/README.md`](../../answers/README.md)를 따른다 — `## <slug>`가 화자 구분자다
6. `node scripts/check-answer.mjs answers/<파일> --write`를 실행한다
7. **위조급 위반이 있으면** 해당 위인만 위반 내역을 프롬프트에 넣어 **1회** 재호출하고,
   파일을 갱신한 뒤 다시 검사한다. 재시도 후에도 남으면 위반을 명시한 채 출력한다 — 감추지 않는다
8. 형식급 위반은 기록만 하고 답변은 그대로 출력한다
9. 각 위인의 답변을 **그대로** 출력한다. 위인 이름을 소제목으로 달고 순서대로 배치한다

## 출력 뒤에 덧붙일 것

여러 위인이 답했다면 마지막에 **쟁점 한 줄**만 적는다 — "이 둘은 X에서 갈린다".
누가 옳은지 판정하지 않는다. 이 줄은 답변 파일의 `## _orchestrator` 섹션에 들어가며,
**각주를 달 수 없다**(규칙 7) — 사회자가 각주를 달면 그건 위인 발언의 합성이다.

그리고 검사 요약 한 줄을 붙인다.

```
근거 검사 — 각주 7건 · 위조급 0 · 형식급 0 · [근거] 4 [적용] 3 [근거없음] 1
```

## 금지

- **위인 발언을 요약하거나 합성하지 않는다.** 요약하는 순간 각주가 끊기고
  누가 무엇을 근거로 말했는지가 사라진다. 이 시스템의 존재 이유가 무너진다
- 각주를 생략하지 않는다. 길어 보여도 그대로 둔다
- 위인이 말하지 않은 결론을 덧붙이지 않는다
- 위인의 `[근거없음]`을 네가 대신 채워 주지 않는다. 근거가 없다는 것도 답이다
