대상: $ARGUMENTS

`curator` 서브에이전트를 호출해 편입을 맡긴다. 인자가 비어 있으면 `raw/` 아래에서
`raw/MANIFEST.md`에 등재되지 않은 파일을 찾아 목록을 보여 주고 어느 것을 편입할지 묻는다.

## curator에게 전달할 것

- 대상 자료의 경로
- 이미 `sources.json`에 있는지 여부 (중복 등재 방지)
- 이 자료가 영향을 줄 만한 위인·개념 페이지 후보

## curator가 끝난 뒤 확인할 것

1. `npm run lint:strict` 오류 0건
2. `git diff --stat` — 수정 범위가 예상과 맞는지
3. 새로 추가된 각주의 티어가 자료의 성격과 맞는지 (논문을 C로, 블로그를 A로 넣지 않았는지)
4. `raw/MANIFEST.md`에 등재됐는지

하나라도 어긋나면 되돌리고 원인을 보고한다. **통과가 목적이 아니라 근거 무결성이 목적이다.**

## 위인 에이전트 재생성

위인 페이지의 프론트매터(`title`·`role`·`life`·`concepts`·`related`)가 바뀌었으면
`npm run gen-agents`를 실행해 에이전트를 다시 만든다. 위키가 정본이고 에이전트는 파생물이다.
